# 凸包（Andrew 单调链）

> 复杂度： $O(n \log n)$。
> 注意：点去重、共线处理（`<=` 去共线 / `<` 保留全部共线点）、用 `long double` 防精度坑。

```cpp
#include <bits/stdc++.h>
using namespace std;
struct P { long double x, y; };
long double cross(const P&a,const P&b,const P&c){    // ab x ac
    return (b.x-a.x)*(c.y-a.y)-(b.y-a.y)*(c.x-a.x);
}
vector<P> hull(vector<P> p){
    sort(p.begin(),p.end(),[](const P&a,const P&b){
        return a.x<b.x || (a.x==b.x && a.y<b.y);
    });
    p.erase(unique(p.begin(),p.end(),[](const P&a,const P&b){
        return a.x==b.x && a.y==b.y;
    }),p.end());
    if(p.size()<=1) return p;
    vector<P> h;
    for(auto&o:p){                 // 下凸壳
        while(h.size()>=2 && cross(h[h.size()-2],h.back(),o)<=0) h.pop_back();
        h.push_back(o);
    }
    int sz=h.size();
    for(int i=(int)p.size()-2;i>=0;i--){   // 上凸壳
        while(h.size()>sz && cross(h[h.size()-2],h.back(),p[i])<=0) h.pop_back();
        h.push_back(p[i]);
    }
    h.pop_back();                  // 去掉重复首点
    return h;
}
int main(){
    int n; cin>>n; vector<P> p(n);
    for(auto&v:p) cin>>v.x>>v.y;
    auto h=hull(p);
    long double per=0;
    for(int i=0;i<(int)h.size();i++){
        int j=(i+1)%h.size();
        per+=hypotl(h[j].x-h[i].x,h[j].y-h[i].y);
    }
    cout<<fixed<<setprecision(2)<<per<<"\n";
    return 0;
}
```

## 变体
- **旋转卡壳（凸包直径）**：最远点对用双指针扫，维护单峰； $O(n)$（凸包点数）。
- **半平面交**（空心区域求凸形/判空）：极角序 deque，选学。

## 坑
- `cross<=0` 会删掉边上共线点（求周长不含中间点正确）；若想保留边界点用 `<0`。
- 排序用 pair 比较；`hypotl` 或手写 sqrt 保持精度。
- 只返回凸包闭合顺序（逆时针）。
