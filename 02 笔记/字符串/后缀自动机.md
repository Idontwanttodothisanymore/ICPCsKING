# 后缀自动机 (SAM)

## 核心思想
- 对字符串 s 构造的**最小 DFA**，能识别 s 的所有子串。每个状态代表一组**endpos 等价类**（一个区间 [minlen, maxlen]）。
- 增量构造：每加一个字符，新建最长状态 last，沿 link 链补齐转移，必要时 clone 分裂。

## 关键性质（做题核心）
- **endpos 等价类**：两个子串出现在完全相同的末位置集合当且仅当分到同一状态。结点 maxlen = 该状态最长子串长度，minlen = link 的 maxlen+1。
- **parent 树**（后缀链接树 / fail 树）：积父子关系下子串包含关系成立。**每个状态的出现次数 = 它在 parent 树上子树的 `cnt` 之和 + 自身 1**（差分/拓扑累计）。
- **len 链单调**：沿 link 走 maxlen 严格减小，深度 $O(n)$。
- SAM 支持 $O(1)$ 判断子串是否存在、$O(n)$ 求不同子串数量 / 出现次数等。**本质不同子串数 = sum(maxlen[v] - maxlen[link[v]])**。

## 常用查询
- 子串出现次数 / 所有不同子串数量 / 字典序第 k 小子串。
- 最长公共子串（两个串拼一起建广义 SAM）。
- **广义 SAM**：多串插入同一个 SAM（last 置根），支持多串统计。
- 配合后缀树 / 后缀数组可互相转换（SAM 的 parent 树=反串的后缀树）。

## 模板
- 模板题：洛谷 P3804（求出现次数 >1 的|len|×次数最大值）。
- P前缀 P4070 [SDOI2016] 生成魔咒（动态插入统计不同子串数）。

## 易错点
- 构造时 **clone 节点要复制全部转移和 link，且 maxlen 不递增**；原节点转移再指向 clone 会影响 dp 累计。
- 出现次数排序按 **maxlen 桶排序**（基数）而非建边 DFS，否则复杂度退化 / 栈爆。
- cnt 只在**增量插入产生的节点 +1**，clone 节点不加；最后按 len 从大到小累加到 link 上。
- 广义 SAM 多串时 last 归根，别跨串连 link 出错。
