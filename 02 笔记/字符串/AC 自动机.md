# AC 自动机

## 核心思想
- **多模式串匹配**的 KMP 推广：把所有模式串建 Trie，为每个节点补 `fail` 指针（失配转移）。
- `fail[u]` = 除自己外最长的"既是 u 表示的串的后缀、又是某模式串前缀"的串对应节点（等于走另一个模式串的最长后缀）。构建用 BFS：`fail[child] = dict[fail[u]][c]`。

## 关键性质
- 对任意节点 u 不断跳 `fail` 生成的所有节点，恰好对应 u 串的**所有后缀中属于模式串字典**的那些 → **fail 树**（fail 指针构成一棵树）。
- **字典图补全**：把不存在的转移补成沿 fail 的转移（`dict[u][c]=dict[fail[u]][c]`），使每次匹配都是 O(1) 前进，自动机成完整 DFA。
- 在 fail 树上做差分 / DFS 序：可对"每个文本位置命中了哪些模式串"做高效计数。

## 应用与计数
- **拓扑序 DP 计数**：沿自动机建立"不出现某模式串"的 DFA，跑 DP 统计长度 L 的合法字符串数量；常配**矩阵快速幂**（状态是自动机节点数）处理大 L。
- **fail 树上差分**：统计每个模式串在文本中出现次数——文本每个字符沿自动机走时的 fail 链贡献，用 DFS 序 + 差分 / 树剖优化。
- 与 AC 自动机相关的**禁止子串**问题（DP + 自动机 + 快速幂）是热门。

> [!example] 例题
> - 洛谷 P3808 【模板】AC 自动机（简单版，统计出现次数）。
> - 洛谷 P3796 【模板】AC 自动机（加强版，输出出现最多的模式串，需 fail 树上算贡献）。
> - P2444 [POI2000] 病毒（禁止子串 + 自动机判环 / DP）。
> - CF 103 F→ 用自动机 + 矩阵快速幂计数"不包含给定词的长度为 n 的串"个数（经典）。

## 易错点
- BFS 建 fail 时对**存在**的 child 与**不存在**的 child 两种处理要统一，勿把不存在 child 无限递归。
- 根节点的 fail 是自身；根没有转移的字符指向根。
- 多测清空 Trie 节点（`ne` 数组、`fail`），注意预分配大小 $n\times len$。
- 沿自动机匹配时，每走一步要**把所有 fail 链上出现的模式串都计入**（可用 fail 树差分避免暴力跳）。
