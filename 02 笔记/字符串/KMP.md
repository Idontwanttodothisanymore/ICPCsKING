# KMP

## 核心思想
- 预处理模式串的**前缀函数** $\pi[i]$ = 前缀的长度满足"长为 $\pi[i]$ 的前缀恰好是长为 $i$ 的后缀"的最大值（border）。
- 匹配时失配不从头来，而是把模式串右移回退到 $\pi[上一个]$ 继续比，均摊 $O(n+m)$。

## 关键性质
- **border 链**：不断取 $\pi[ \pi[i] ]...$ 得到所有可能的 border 长度，即"既是前缀又是前缀"的所有位置。
- **周期性（Periodicity Lemma / 最小周期）**：若 $s$ 有长度为 $p$ 的周期（$s[i]=s[i+p]$），当且仅当长为 $n$ 的串存在 border 长度 $n-p$。**最小周期 $= n - \pi[n-1]$**，若整除则是最小循环元。
  - 例：$ababab$ 的 $\pi[5]=4$，最小周期 $p=2$，说明 $ababab$ 由 $ab$ 循环。**判断整个串可被某子串循环覆盖**的核心手段。
- 前缀函数本身可用于区间 border 查询、双重 KMP 等。

## 模板
- 模板题：洛谷 P3375【模板】KMP
- 前缀函数 $O(n)$：`for i in 1..n-1: j=pi[i-1]; while j>0 && s[i]!=s[j] j=pi[j-1]; if s[i]==s[j] j++; pi[i]=j`。

^[注] 前缀函数与 Z 函数等价，可互相推导。也常与 AC 自动机（多模式串）配合。

## 易错点
- 前缀函数下标习惯：`pi[0]=0`，匹配时失配回退 $pi[i-1]$，注意首字母处理。
- 模式串与文本串长度边界；空串/单串判断。
- 求最小周期先判断是否整除（`n % (n - pi[n-1]) == 0`），否则为更大。
- 匹配过程别提前退出；多用 `s[i]==t[j]` 双循环勿混下标。
