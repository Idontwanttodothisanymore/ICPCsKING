笛卡尔树是一种给序列定制的二叉树，他的形状由元素间的大小决定，同时又把序列的位置顺序包留下来。

##### 性质

- 堆性质：每个节点的值都小于他的两个儿子；
- BST 性质：按照中序遍历这棵二叉树，得到的下标是 $1\sim n$ 。

##### 构造技巧

**使用单调栈维护 “右链”**。以下是具体的步骤，入栈新节点 $i$ 时：

1. 把栈中所有大于 $a_{i}$ 的元素弹出。这些都比 $a_{i}$ 大，只能待在子树里。又因为要满足 BST 性质，所以要先遍历子树在遍历根 $i$，因此所有大于 $a_{i}$ 的元素只能待在 $a_{i}$ 的左子树里；
2. 最后一个被弹出的节点成为 $i$ 的左儿子；
3. 弹完之后的剩下的栈顶成为 $i$ 的父亲，即把 $i$ 挂在右儿子上。依旧是为了满足 BST 的性质，不能挂在左儿子；
4. $i$ 入栈。

##### 代码

注意区分 $i$ 与 $a_{i}$。

```cpp
stack<pii> st;
st.push({a[1], 1});
for (int i = 2;i <= n;++i) {
	int lst = 0;
	while (!st.empty() && st.top().first > a[i]) {
		lst = st.top().second;
		st.pop();
	}
	if (!st.empty()) r[st.top().second] = i;
	st.push({a[i], i});
	l[i] = lst;
}
```
##### 应用

最主要的应用就是把序列问题转化为树上的问题。比如可以把 RMQ 问题上树，转化成 LCA，从而获得比线段树 / ST 表更优秀的复杂度。不过也就少一个 $\log$ ，其实差不多。

Treap 其实就是通过随机化的过程把保证树的深度是 $\log n$ 的级别。Treap 通过随机化 priority 当做小跟堆处理的元素，把真正要存的值放到了 key 里面，对比上面的笛卡尔树，其实是反过来了。
