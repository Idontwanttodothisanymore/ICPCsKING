# 网络流

## 最大流
- **Dinic**：BFS 分层（level 图）+ 当前弧优化 DFS 多路增广。 $O(n^2m)$（一般图）/ $O(m\sqrt n)$（二分图单位容量），实际极快，是默认板子。板子见 [[Dinic]]。
- **残量网络**：正向流 + 反向边（容量=已用流量）实现退流，这是所有增广算法的基石。
- 常用技巧：重边合并、超源/超汇、拆点限流（一个点拆成出/入两半，中间连容量=点容量）。

## 最小割
- 最大流 $=$ 最小割（**最大流最小割定理**）。
- **建模（集合划分）**：把每个元素看成被丢到 S 侧或 T 侧，代价用割边表达。经典：
  - 两个源（黑点/白点）与汇，元素只能在一侧，若同时在两侧则惩罚 → 罚边跨 S/T 被计入割。
  - 网格染色成二分（黑白），对立限制转成"选中黑+选中白"与"都不选"的对比，用最大点权独立集： $ans = \sum正权 - 最小割$。
- **最大权闭合子图**：选一个点必须选它的所有后继， $ans = \sum_{正权} - mincut$。建模：源连正权点容量=权，负权点连汇容量=-权，依赖关系连 INF 边。

## 费用流
- 每次选最短（最便宜）增广路，用 SPFA / Bellman-Ford 或 Dijkstra+势（Johnson）保证非负权。
- 复杂度更高，注意流量倍增 / 费用为负时用势。
- **可行流 + 费用最优**：若图里同时要求满足某个流的大小（如每个商店需求），费用流天然最优化总费用。

## 建模套路（最重要，靠刷题积累）
- **拆点**：限制点容量 / 点权——点拆成 `u_in -> u_out`，边权为点容量。
- **拆边**：分层边（如限制每天），分流量不同代价（优惠价/全价两段边）。
- **上下界可行流**：无源汇 / 有源汇，先跑自由流再判可行性（超源超汇补流量）。
- **黑白染色二分图** + 最大权独立集，网络流经典模板（最常见）。
- **二分图/偏序类最小路径覆盖**、**最大权值分配**（左侧资源到右侧任务）。
- 多源多汇 → 建超大源超大汇。

## 易错点
- 反向边容量=已用流量（流量守恒回复），**初始正向边容量=题目容量，反向 0**。
- Dinic 层数 BFS **必须重建每次**，`level` 只是到当前迭代的分层，DFS 完丢掉。
- 当前弧优化数组 `cur[]` 必须每层重置，否则提前退流导致 WA。
- 拆点注意容量方向（限流在接入边），别把点容量加到不该加的地方。
- 费用流 Dijkstra 势的 `h[v]=h[u]+w+pot[u]-pot[v]`，初值为最短路；负环/detailed 的边界多测清图。
