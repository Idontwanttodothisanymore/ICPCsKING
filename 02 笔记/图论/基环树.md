# 基环树

## 结构
- n 点 n 边（比树多一条边）连通图：恰有一个环。分**无向基环树**、**有向内向 / 外向基环树**（功能图 Functional Graph）。
- 每个弱连通分量由若干树反过来接到一个环上。判定： $\sum deg$、并查集判断环、拓扑剥离。

## 处理套路（核心：断环成树）
- **找环**：拓扑剥离——不断删度数为的叶子，剩下的是环。或 DFS 维护访问栈找环（记录环上顶点顺序）。
- **断环成树**：对环上的每个点向下挂的子树是普通树，先对每条子树单独 DP；环上部分再单独做「环上 DP」。
- **环上 DP**：环上选点带相邻限制（如不能同时选相邻环点）→ 破环成链，做两遍线状 DP（**枚举第一个点选/不选**），取较优。

> [!example] 例题 · 洛谷 P2607 [ZJOI2008] 骑士
> 每个点有权值，不能同时选有边相邻的两点，图是多个基环树（可能有重边）。做法：找环，对环上每个点强制不去算一次子树树形DP，环上再按"首点选否"做两遍，答案是各连通块最大值之和。经典考察断环成树 + 破环两遍DP。

> [!example] 例题 · CF1996G Penacony（库内已写题解）
> 环上若干小区间的覆盖问题，用**环上差分 + 异或哈希**计数覆盖，见 [[CF1996G Penacony（环上差分+异或哈希）]]。

## 典型问题
- 内向基环树上从某点出发走 k 步到哪（倍增跳环 + 环上偏移）。
- 环上最短路：把环排成两倍长差分，配合二分/双指针。
- 环 + 树的 DP（骑士）、环上删边后的最小生成树（枚举删哪条环边）。
- 统计到环的距离、子树大小（反向建树）。

## 易错点
- 有重边 / 自环的特殊考虑：DFS 找环时要排除"走回父亲的那条边"（记父边而非父点）。
- 环必须**去重**：拓扑剥离和原图编号对应好，别把环外点误当环点。
- 基环树森林：每个连通分量单独处理，别假设只有一个环。
- 破环 DP 时枚举首点选否，状态是"相邻不能同选"，边界清理不能漏。
