# 计算几何

## 基础
- **叉积** $a\times b=|a||b|\sin\theta$：符号判左右、两倍面积；**点积** $a\cdot b=\cos\theta$：判锐钝、投影长度。
  - `cross<0` 点在向量右侧；`cross(a,b)` 可用于三点共线判定与极角排序。
- **点在多边形内**：射线法（与边求交奇偶）+ 边界特判。
- **线段相交判定**：跨立试验（叉积异号）+ 共线特判。

## 凸包
- Andrew 单调链 $O(n\log n)$：按 x 排序后正反各扫一遍维护下/上凸。板子见 [[01 模板库/几何/凸包|凸包]]。

## 经典专题
- **旋转卡壳**：凸包上求最远点对（直径），双指针伴随转动扫凸包，$O(n)$（凸包构建后）。经典最小外接矩形也用。
- **半平面交**：每条半平面 $ax+by+c\le0$，对极角排序列入 deque（选学）。
- **最小圆覆盖**：随机增量法 O(n)。
- **圆与多边形面积交**：把圆心角积分转成三角形-扇形容斥。
- **扫描线求交**（两多边形并/交）、**凸多边形相交的半平面交 / Minkowski 和**。

## 精度处理（几何题 90% 的坑）
- **eps 选取**：$10^{-8}$ 常用，比较用 `sgn(x)=x>eps?1:x<-eps?-1:0`，杜绝 `==`。
- **避免除法 / 开方后比较**：用叉积判序、用"平方距离"比较，尽量不 `sqrt`。
- 需要精度的用 `long double`，输出按题目位数。
- 叉积可能溢出 int → 用 `long long` / `long double`。

## 易错点
- 极角排序稳定性、点去重（凸包结果重复点）。
- 半平面交排序的相同极角去重、首尾合并。
- 多边形面积用叉积和的一半，注意有向面积符号。
- `==` 比长 double 必炸，统一 `sgn`。
