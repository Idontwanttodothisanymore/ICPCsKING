# DP 优化方法大杂烩

> 本页按「优化对象」分类，重点在**识别信号**——看到什么形式的转移方程能套哪种优化。复杂度从暴力 $\Theta(n^2)$ 压到 $\Theta(n\log n)$ 或 $\Theta(n)$。

## 单调队列优化
- **适用**：转移方程形如 $dp[i]=\max_{j\in[i-k,i-1]}\{dp[j]+w(j)\}$，即候选决策的下标在**一个滑动窗口**里，且代价只与 $j$ 有关（不含 $i\cdot j$ 交叉项）。
- **做法**：维护决策下标队列，队头始终是当前窗口最优；每次 i 前进时先弹出窗口外下标，再弹出被新决策单调支配的队尾，最后插入 i。
- **原理**：贡献 $dp[j]+w(j)$ 与 $i$ 无关，等价于对一维结构求滑动最值，用单调队列 $O(n)$。

> [!example] 例题 · 洛谷 P3957 跳房子
> 位置 0 出发，单次跳跃距离需落在 $[\max(1,d-g), d+g]$（g 为二分出来的弹跳力），每个格子有权值。单调队列在窗口内维护 $max\{dp[j]\}$，队头即为最优转移， $O(n)$ 判可行性，外层二分 g $O(\log)$。

## 斜率优化（李超 / 单调栈）
- **适用**：转移能写成 $dp[i]=\min_j\{dp[j]+a[i]\cdot b[j]+c[i]+d[j]\}$，出现**交叉项 $a[i]\cdot b[j]$**。
- **做法**：把每个 $j$ 看成直线 $y=kx+b$（ $k=b[j],\ b=dp[j]+d[j]$）， $dp[i]$ 即拿 $x=a[i]$ 对全直线取最值。斜率与查询点均单调 → 单调栈保凸壳 + 队头指针；否则斜率二分 / 李超线段树。
- 详见 [[斜率优化]]。

## 决策单调性（分治 / 四边形不等式）
- **适用**：区间 / 序列划分式 $dp[i][j]=\min_k\{dp[i-1][k]+w(k,j)\}$，且 $w$ 满足**四边形不等式** $w(a,c)+w(b,d)\le w(a,d)+w(b,c)$。
- **两种形态**：
  - **分治优化**： $opt[i][j]$ 随 i 单调，用分治每层只扫候选区， $O(n\log n)$。
  - **四边形不等式（夹逼）**： $opt[i][j-1]\le opt[i][j]\le opt[i+1][j]$，收紧枚举区，总 $O(n^2)$（去一层 log）。

> [!example] 例题 · 洛谷 P4767 邮局
> 数轴上 n 个村庄选 p 个邮局使到最近邮局距离和最小。 $dp[i][j]=\min_k\{dp[k][j-1]+cost(k+1,i)\}$，cost 满足四边形不等式 → 四边形不等式优化把枚举 k 收紧，显著压常。

## 数据结构优化
- **适用**：转移为区间最值 / 求和查询，代价可任意。把已算的 $dp[j]$ 按下标 / 值域插进线段树 / BIT，转移 $O(\log n)$。
- 变体：按 `a_j` 值域建树、按模余数分组、按属性位分解。

> [!example] 例题 · 洛谷 P4310 绝世好题
> 最长子序列使相邻 and>0。令 $g[b]$ 存末尾二进制含位 b 的最长长度， $dp_i=\max_j\{dp_j\}+1$ 对 $a_i$ 每个 set 位取 max， $O(n\log V)$——本质是"按属性建多个最值结构"。

## 矩阵加速
- **适用**：线性递推 $f_n=c_1f_{n-1}+\cdots+c_kf_{n-k}$，k 小 n 大（ $\le 10^{18}$）。 $O(k^3\log n)$ 快速幂。
- 详见 [[矩阵]]。

## WQS 二分（凸优化）
- **适用**：**恰好选 k 个**的优化问题，去掉数量限制后是凸的且易解，选择数与"单价"单调。
- **做法**：给每个选择附加单价值 $C$，原问题的选数 $g(C)$ 随 C 单调。二分 C 使 $g(C)=k$，答案 $=$ 无限制最优 $-C\cdot k$。

> [!example] 例题 · 洛谷 P4383 林克卡特树（简化）
> 选恰好 $K+1$ 条链覆盖树的最大权。带 K 限制二维 DP $O(nk)$；WQS：给每条链加单价 C 后回归一维 DP $O(n)$，二分 C 收敛到实际链数。

## 易错点
- 单调队列：窗口开闭下界统一，避免未更新完的 $dp$ 提前入队。
- 斜率优化：cross 乘法判斜率避免 double 误差；max/min 决定凸壳上下方向。
- 决策单调：夹逼必须 $opt[i][j-1]\le opt[i][j]\le opt[i+1][j]$，漏下限 WA。
- 矩阵：转移向量与矩阵行列对应、幂起始次数（决定首项）。
- WQS：二分的是单价非数量；答案需减 $C\cdot k$；处理相等值选多/选少的方向。
