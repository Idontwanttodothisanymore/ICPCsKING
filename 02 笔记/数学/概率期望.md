# 概率期望

## 基础
- **期望线性性（最重要）**：$E[\sum X_i]=\sum E[X_i]$，对任意相关/无关都成立——大概率题的核心武器，把复杂变量拆成指示变量之和。
  - 例：随机排列中固定位置逆序对期望 = $E[\sum_{对}(0 或1)]=\binom{n}{2}\cdot\frac12$。
- **全期望（条件期望）公式**：$E[X]=\sum_j P(B_j)E[X|B_j]$；条件概率 $P(A|B)=P(A\cap B)/P(B)$。

## 期望 DP
- **正推 vs 逆推的选择**：
  - **逆推（推荐起点）**：$E_i = \sum p_{ij}(E_j+c_{ij})$，从目标态向起点转移，适合"求从 i 走到终点的期望步数"。
  - **顺推**：求"从起点到 i 的期望"，要注意消元（可能出现依赖闭环）。
- **概率 DP 与期望 DP 分开做**：先算概率再算期望，别混。常见设 $dp[i]$=从 i 到终点的期望步数。

## 经典模型
- **几何分布**：独立试验成功概率 p，首次成功所需次数期望 $E=1/p$。
- **随机游走**：$E_i=1+\frac12(E_{i-1}+E_{i+1})$ 型，可用边界消元 / 高斯消元解线性方程组。
- **吸收马尔可夫链 / 期望步数**：抽象成状态转移的线性方程，**高斯消元**求解（$n$ 不大时）。
- **换元 / min-max 容斥**：求"所有元素都被收集的期望时间"= min-max 容斥转换；或事件"每个都到过一次"拆成指示变量。
- 与生成函数结合：终止状态概率分布、步数生成函数 → 见 [[生成函数]] 与库内 ABC473G 题解。

## 易错点
- 模意义下分数 $=\times inv$：期望值在 mod 下先取逆元，别直接 double 输出（除非题义要 real）。
- 逆推/顺推方向写反错；有环时直接 DP 会死循环——**判断是否要高斯消元**。
- 指示变量的选择：要选的"事"是否互斥、线性性好不好。
- 无限期望要判断收敛（几何/吸收类 $p>0$ 才能套 $1/p$）。
