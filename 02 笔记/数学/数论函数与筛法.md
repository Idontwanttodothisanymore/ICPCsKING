# 数论函数与筛法

## Euler 函数 $\varphi$
- $\varphi(n)$ = 1..n 中与 n 互质的数个数。
- 性质： $\varphi(p^k)=p^{k-1}(p-1)$ 配合积性积出； $\varphi$ 是**积性函数**。
- $n=\sum_{d|n}\varphi(d)$（欧拉三角恒等式，常用于反演）。
- 线性筛时： $i\bmod p=0$ 则 $\varphi(ip)=\varphi(i)\cdot p$；否则 $\varphi(ip)=\varphi(i)\cdot(p-1)$。

## 线性筛
- 在 $O(n)$ 内筛出：质数、 $\varphi$、 $\mu$（莫比乌斯）、约数个数 $d$、约数和、最小质因子。
- 原理：每个合数只被其**最小质因子**筛一次。核心 `for p in primes: if p>minp[i] break`。

## 莫比乌斯函数 $\mu$
- 定义与关键恒等式： $\sum_{d|n}\mu(d)=[n=1]$。反演工具，与 [[莫比乌斯反演]] 承接。

## Dirichlet 卷积
- $(f\ast g)(n)=\sum_{d|n}f(d)g(n/d)$，单位元 $\varepsilon$（ $\varepsilon(1)=1$，其余 0）。积性函数卷积仍积性。
- 常见恒等式： $\mu\ast 1=\varepsilon,\ \varphi\ast 1=\text{id},\ 1\ast 1=\text{d}$（约数个数）。详见 [[莫比乌斯反演]]。

## 数论分块（整除分块）
- $\sum_{i=1}^n \lfloor \frac{n}{i}\rfloor$： $\lfloor n/i\rfloor$ 在连续区间内取值相同，区间右端 $r = n/(n/l)$，每段 $O(1)$ 计算。总 $O(\sqrt n)$ 段。
- 与 $\sum f(i)$ 前缀和、或 $\mu/\varphi$ 前缀积结合是杜教筛基础。

> [!example] 例题 · 洛谷 P2261 [CQOI2007] 余数求和
> $\sum n \bmod i = n\cdot k - \sum i\lfloor n/i\rfloor$，用整除分块每段等差数列求和， $O(\sqrt n)$。最经典入门分块题。

## 杜教筛 / Min_25 筛（选学）
- **杜教筛**：求 $S(n)=\sum_{i\le n}f(i)$，利用 $f$ 与某 $g$ 的卷积出递推 $S(n)$，配合整除分块 $O(n^{2/3})$。典型： $\mu$、 $\varphi$ 前缀和。
- **Min_25 筛**：质数处取值构造，处理 $\le 10^{11}$ 的积性函数前缀和（选学）。

## 易错点
- 线性筛数组下标到 n 别漏，`vis` 标记；多测记得清。
- $\varphi$ 线性筛两种情形（整除/不整除质因子）公式别混。
- 整除分块右端 `r = n/(n/l)` 当 l 超过 n 会除 0/越界，限制 `min(r,n)`。
- 取模与 long long： $\sum i\lfloor n/i\rfloor$ 用等差数列乘 $\lfloor \rfloor$ 可能溢出。
- 杜教筛记忆化用 map 或数组（n 到达大时数组不可行选 map）。
