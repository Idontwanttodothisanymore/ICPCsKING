# 线性基

## 异或线性基
- 一组数在 $\mathbb{F}_2$ 下张成的线性空间的规范基，能表示原集合所有数的异或结果。
- **构造**：逐个插入 $x$，从高到低消元；若某位无主则占位，否则 $x\ \oplus=$ 主元对应基数。
- **性质**：线性基大小 $\le 位宽$（如 60）。原集合可表示的和集 $=$ 线性基张成的和集；**集合中每个数可由基线性表出**。

## 查询
- **最大异或和**：贪心从高位向低位尝试 `ans=max(ans, ans^b[i])`。
- **第 k 小异或值**：先把线性基消成**行最简（最高位唯一）**，把 k 的二进制位对应选或不选基元，拼出第 k 小。
- **存在性**查询：某数能否被表示。

## 性质与高级操作
- **线性基求交 / 求并**：两基张成空间之交 = 各自补基的维数关系，可用"加入对偶"法 O(维²)。
- 线性基可**合并**：把 b 逐个 insert 进 a。
- 往往配合**高斯消元**：本质上就是异或意义的高斯消元，很多"异或方程组"问题 = 建线性基判解/数解。

## 应用
- **异或方程组**（模 2 线性方程组）：判断解、自由元个数 ( $= 位数-$秩)，方案数 $2^{自由元}$。
- **图上任意路径的异或和集合**：等于"某个生成树路径异或 与 所有非树边形成环的异或"的线性基所张成的空间（选起点到某点路径，环自由叠加）。经典：所有点路径异或可行值 = {dis 到根的 xor} + 环线性基。
- 配合平面上"选若干个数取异或最大化"都是线性基模板。

## 易错点
- 线性基要**从高到低**插入，第 k 小要先把矩阵化成行最简（只保留每列最高位的那个1）再做。
- 插入时用 `if(!x) return false`（向量已在前基里），判断能否被表示。
- 合并两基时复杂度按维,O(位宽²)。
- 图路径异或别忘"初始 = dis[目标]"，环贡献通过基叠加。
- 线性基存的是**基向量**，不是原集合元素，别拿错。
