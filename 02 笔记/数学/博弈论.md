# 博弈论

## 核心理论
- **公平组合游戏 (ICG)**：两人轮流、有限操作、无随机、双方信息完全、不能行动者负。终态为必败态（P-position）。
- **Sprague-Grundy (SG) 定理**：多个独立子游戏的组合，其 SG 值为各子游戏 SG 的 **nim 和（异或）**。**SG = 0 ⇔ 必败态**。
- **SG 函数**：$SG(x)=\text{mex}\{SG(后继状态)\}$。计算每个状态的可达状态 SG 值取最小未出现。

## 经典模型
- **Nim**：n 堆石子，任取一堆任意个，$a_1\oplus\cdots\oplus a_n=0$ 必败。即最经典 SG 应用。
- **Bash**：每回合取 1~m 个，$(n \bmod (m+1))\neq0$ 先手胜。
- **Anti-Nim**（取完者输）：一般情况仍看异或，但**特判全为 1** 时反立：(n 全为1) 且 $n$ 偶 → 先手胜，否则异或非 0 的规则。库内标出的重点坑。
- **翻硬币 / 取模**：常转成"谁拿到最后一个可赢"，归结为 SG。
- **树上删边（Green Hackenbush）**：每条边一根"绿棍"，SG = 子树 SG 的异或，配柯尔莫哥洛夫树剪/GE 简化（选学）。

## 非公平 / 对抗搜索
- **min-max 记忆化**：两方目标相反，DFS+记忆化取 max/min，博弈树状态少时可行。
- 状态巨大的博弈（棋盘类）常**不能记忆化**，需找结论 / 打表猜规律（配合 [[猜结论与归纳技巧]]）。

## 易错点
- **Anti-Nim 全 1 特判**；其余按普通 Nim 判。
- SG 的表的边界：某状态无可达状态时 SG=0（必败），别漏。
- 多子游戏时是对**子游戏 SG 异或**，不是直接状态异或；状态可分解要先找出 SG。
- min-max 题注意"先手胜/负"与评分，别把取 max 与取 min 写反。
- 打表规律要注意周期性与单状态阶乘规律的边界。
