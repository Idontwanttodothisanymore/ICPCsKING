# 生成函数

## OGF（普通生成函数）
- $F(x)=\sum_{n\ge0}a_n x^n$。 $[x^n]F$ = 序列第 n 项。
- **计数**：两个箱子组合方案数 = OGF 相乘（加法对应并、乘法对应笛卡尔积）。
- **常见封闭形式**： $\frac1{1-x}=1+x+x^2+\cdots$， $\frac{1}{(1-x)^k}$ 对应广义二项系数；有限集选 k $\binom{n}{k}$ 的 $(1+x)^n$。

## EGF（指数生成函数）
- $F(x)=\sum\frac{a_n}{n!}x^n$。用于**标号对象**（有标签的组合结构）。
- **exp 的组合意义**： $e^{F(x)}$ 表示"把对象分成若干块组合的集合"。标号乘法对应组合结构（labeled species）。

## 应用
- **递推 → 封闭形式 → 系数提取**：先写出 OGF 封闭式，再用幂级数展开取 $[x^n]$。典型：Catalan、斐波那契。
- **概率分布的卷积**：终止时刻的分布、掷骰子和 → 各自 OGF/收敛级数相乘，如库内 [[ABC473G Wipeout（生成函数+分治NTT）]]。

## 易错点
- OGF 与 EGF 的选择：**无标签计数用 OGF，有标签（标号对象）用 EGF / exp**。
- 系数提取别忘分母阶乘（EGF 的 `[x^n]` 对应 $\frac{a_n}{n!}$）。
- 多项式取模 / NTT 长度要是 $2^k$ 且够大（卷积缩长度），分治 NTT 注意每层莫忘模。
- 递推写封闭式注意初值（ $x^0$ 项），少写一项整题量爆。
