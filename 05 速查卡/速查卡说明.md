# 速查卡说明

> [!info] 用途
> `05 速查卡/` 存放**赛前打印用**的浓缩版本：只有结论、公式、代码，没有证明和推导。赛场 5 小时翻的是这里，不是 `02 笔记/`。

## 与笔记的关系

- 笔记（`02 笔记/`）负责"学会"，速查卡负责"用上"
- 一篇笔记成熟后，抽其中的**结论块 + 模板块**进速查卡，用 `![[...]]` 嵌入或手抄精简版
- 速查卡控制在 25 页以内（ICPC 纸质资料上限量级）

## 建议的速查卡页序（打印顺序）

1. 复杂度速查表（数据范围 → 能接受的复杂度）
2. 模板：图论 / 数据结构 / 字符串 / 数学 / 几何
3. 常见公式：组合数、容斥、期望线性性
4. 易错 checklist（long long、边界、模意义）
